OLS Regression

Concept Relationship Map
The Model
True Model
Y = Xβ + ε
The data-generating process. β and X are fixed constants. Y is random because ε is random. We never observe the true β.
feeds → OLS objective feeds → ε assumptions
ε (Error Term)
ε ~ N(0, σ²I)
Captures noise, omitted variables, measurement error. Zero mean means OLS is unbiased. Normality justifies t and F tests. σ² is unknown.
feeds → σ̂ estimation enables → inference
E[Y | X]
E[Y|X] = Xβ
The mean function — the systematic part of the model. This is what Ŷ estimates on average. ε vanishes when taking expectations since E[ε] = 0.
feeds → Ŷ (unbiased)
Estimation via OLS
S(β) — OLS Objective
S(β) = (Y − Xβ)ᵀ(Y − Xβ)
The sum of squared residuals as a function of any β. Expanding gives YᵀY − 2βᵀXᵀY + βᵀXᵀXβ. We minimize this over all possible β values — β̂ is not yet known at this stage.
feeds → normal equations (via derivative) feeds → SSE (evaluated at β̂)
Normal Equations
XᵀXβ = XᵀY
Setting ∂S/∂β = 0. Called "normal" because residuals are orthogonal (perpendicular) to col(X) — not related to the normal distribution.
feeds → β̂
Key Quantities
β̂ — OLS Estimator
β̂ = (XᵀX)⁻¹XᵀY
Solves the normal equations. BLUE by Gauss-Markov (needs E[ε|X]=0, homoskedasticity). Also the MLE when ε is normal. Requires XᵀX invertible.
feeds → Ŷ feeds → residuals enables → t-test
Ŷ — Fitted Values
Ŷ = Xβ̂ = HY
The projection of Y onto col(X). H = X(XᵀX)⁻¹Xᵀ is the hat matrix. H is symmetric (Hᵀ=H) and idempotent (H²=H). E[Ŷ] = Xβ.
uses → β̂ feeds → residuals feeds → R²
Residuals
e = Y − Ŷ = (I−H)Y
Observed minus fitted. Not the same as ε (true error). Orthogonal to Ŷ by construction. Used to check model assumptions and estimate σ².
from → Ŷ and Y feeds → SSE feeds → diagnostics
Inference
SSE
SSE = Σ(yᵢ−ŷᵢ)² = eᵀe
Sum of squared residuals — how much variation the model cannot explain. S(β) evaluated at β̂. Smaller SSE means better fit.
from → residuals feeds → σ̂, R²
σ̂ (s) — Residual Std Error
s = √(SSE / (n−p))
Estimates the unknown σ from ε ~ N(0,σ²I). Dividing by n−p (not n) makes it unbiased — p degrees of freedom are used estimating β. Appears in R summary output.
from → SSE feeds → SE(β̂)
Var(β̂) & SE(β̂)
Var(β̂) = σ²(XᵀX)⁻¹
SE(β̂ⱼ) = s√[(XᵀX)⁻¹ⱼⱼ]. In SLR: SE(β̂₁) = s / √Σ(xᵢ−x̄)². More spread in x → smaller SE → more precise estimate.
uses → σ̂, XᵀX feeds → t-test, CIs
Tests & Model Fit
t-statistic
t = (β̂ⱼ − c) / SE(β̂ⱼ)
Tests H₀: βⱼ = c (usually c=0). Follows t(n−p) distribution because σ is estimated. Significant → evidence the predictor has a real linear relationship with Y.
uses → β̂, SE(β̂) enables → p-values, CIs
R²
R² = 1 − SSE/SST
Proportion of variance explained. Never decreases when adding predictors. High R² ≠ correct model — a true model can have R²≈0 if σ² is large relative to signal.
from → SSE, SST feeds → adj. R²
Adjusted R²
1 − [(1−R²)(n−1)/(n−k−1)]
Penalizes for number of predictors k. Can decrease when adding unhelpful predictors. Better for comparing models of different sizes than raw R².
from → R², n, k enables → model comparison
